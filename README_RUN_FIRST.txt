CAREERFORGE AI - RUN FIRST

1. Extract this ZIP.
2. Open the extracted CareerForge-AI folder.
3. Double-click setup_backend.bat once.
4. Then double-click run_backend.bat.
5. Open http://127.0.0.1:5000 in your browser.

The included Flask backend, database, ML assets, NLP parser, templates and static frontend are already in this folder.

If Python 3.11 is not installed, install Python 3.11 and make sure the `py` launcher is available.

Do not upload .env to GitHub. Use .env.example as the template for local secrets.
